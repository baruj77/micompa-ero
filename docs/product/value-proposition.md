# Propuesta de valor

## Usuario principal

Persona mayor relativamente autónoma que utiliza un teléfono Android y presenta dificultades con aplicaciones convencionales.

## Comprador probable

Familiar o cuidador que busca facilitar acompañamiento, recordatorios y comunicación.

## Problemas observables

- Interfaces móviles complejas.
- Dificultad para encontrar contactos o funciones.
- Recordatorios dispersos.
- Dependencia de terceros para configurar el teléfono.
- Comunicación familiar fragmentada.

## Solución propuesta

Una aplicación Android con interacción prioritaria por voz, botones grandes, navegación mínima, agenda, recordatorios, contactos visuales, mensajería familiar y solicitud de ayuda.

## Beneficios hipotéticos

- Menor fricción tecnológica.
- Mayor autonomía cotidiana.
- Comunicación familiar más simple.
- Menor costo inicial al utilizar un teléfono existente.
- Disponibilidad dentro y fuera del hogar.

## Diferenciadores hipotéticos

- Diseño específico para personas mayores.
- Voz como interacción principal, no exclusiva.
- Memoria personalizada solo con autorización.
- Participación familiar sin acceso automático a conversaciones privadas.

## Alternativas actuales

Asistentes de voz generalistas, alarmas del teléfono, WhatsApp, llamadas convencionales, calendarios y apoyo directo de familiares.

## Hipótesis comerciales pendientes

- El familiar estaría dispuesto a pagar una suscripción mensual.
- Una parte de los usuarios preferiría un servicio de configuración inicial.
- El ahorro de comprar una tablet facilitaría la adopción.

Estas hipótesis deben validarse mediante entrevistas y piloto; no constituyen evidencia actual.
