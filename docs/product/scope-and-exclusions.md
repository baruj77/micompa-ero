# Alcance preliminar y exclusiones

## Alcance sujeto a validación

- Aplicación Android para persona mayor.
- Conversación por voz con alternativa táctil.
- Agenda y recordatorios.
- Contactos familiares con fotografía.
- Llamadas telefónicas.
- Mensajes, audios y fotografías.
- Botón de ayuda.
- Ubicación puntual y autorizada durante una solicitud de ayuda.
- Actividades sencillas de conversación y memoria.
- Portal web responsive para familiares.
- Consola administrativa y soporte.

## Exclusiones del MVP

- Diagnóstico médico o psicológico.
- Detección de depresión, demencia o deterioro cognitivo.
- Interpretación de signos vitales.
- Integraciones clínicas u hospitalarias.
- Sensores domésticos, relojes o pulseras propios.
- Detección automática de caídas.
- Seguimiento permanente de ubicación.
- Escucha permanente.
- Atención de ambulancias o servicios públicos integrada.
- iOS durante el MVP.
- Aplicación móvil independiente para familiares.
- Smart TV y hardware dedicado.

El alcance no queda aprobado hasta cerrar la investigación y la puerta de validación.
