# Guías de entrevista

## Reglas comunes

- Duración: 30 a 45 minutos.
- No inducir respuestas.
- No infantilizar.
- Pedir permiso antes de observar el teléfono.
- No registrar contraseñas, conversaciones privadas ni datos innecesarios.

## Personas mayores

1. ¿Para qué usa normalmente su teléfono?
2. ¿Qué acciones le resultan fáciles y cuáles difíciles?
3. Muéstreme, si se siente cómodo, cómo llama a una persona cercana.
4. ¿Cómo recuerda medicamentos, citas o actividades?
5. ¿Ha utilizado alguna vez comandos de voz?
6. ¿En qué situaciones le serviría hablar con una aplicación?
7. ¿Qué le generaría desconfianza o molestia?
8. ¿Qué información no querría compartir con familiares?
9. ¿Aceptaría compartir ubicación al pedir ayuda? ¿Bajo qué condiciones?
10. ¿Probaría una aplicación como esta durante algunas semanas?

## Familiares o cuidadores

1. ¿Qué situaciones cotidianas le preocupan?
2. ¿Cómo coordinan actualmente recordatorios y contacto?
3. ¿Qué acciones debería poder configurar remotamente?
4. ¿Qué alertas serían útiles y cuáles invasivas?
5. ¿Qué nivel de privacidad espera para la persona mayor?
6. ¿Usaría mensajes, audios o fotografías dentro del servicio?
7. ¿Qué soporte necesitaría para instalarlo?
8. ¿Pagaría por el servicio? ¿Qué tendría que resolver para justificarlo?
9. ¿Participaría en una prueba piloto?

## Profesionales

1. ¿Qué dificultades tecnológicas observa con mayor frecuencia?
2. ¿Qué errores de diseño deberían evitarse?
3. ¿Qué personas no serían aptas para el MVP?
4. ¿Qué riesgos éticos, de seguridad o privacidad identifica?
5. ¿Qué actividades podrían aportar valor sin presentarse como terapia?
6. ¿Qué condiciones recomienda para un piloto responsable?

## Cierre

- Resumir lo entendido.
- Preguntar si falta algo importante.
- Confirmar autorización para conservar notas anonimizadas.
- Explicar que la conversación no implica atención médica ni compromiso de lanzamiento.
