# Mi Compañero/a

Aplicación móvil de acompañamiento y apoyo cotidiano para personas mayores, diseñada para una interacción simple, accesible y principalmente por voz.

## Estado del proyecto

**Fase 0: validación del problema y fundación del producto.**

En esta fase no existe aún una aplicación funcional. El repositorio contiene el plan maestro, las hipótesis del producto y los instrumentos necesarios para entrevistar a personas mayores, familiares y profesionales antes de iniciar el desarrollo.

## Enfoque inicial

- Android primero.
- Teléfono celular como dispositivo principal del MVP.
- Portal web responsive para familiares.
- Voz como interacción principal, con alternativas táctiles.
- Privacidad, consentimiento y autonomía como principios obligatorios.

## Límites

Mi Compañero/a no es un servicio médico, no realiza diagnósticos, no reemplaza a familiares o cuidadores y no garantiza atención de emergencia.
